# AI Coding 开发平台（端到端前端网页应用交付）

本项目实现一个基于 Python 后端 + 浏览器前端的 AI Coding Pipeline 平台，支持：

- 需求分析
- 方案设计
- 架构设计
- 代码编写
- 代码评审
- 交付集成

## 快速启动

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.main:app --reload --port 8000
```

浏览器打开：`http://localhost:8000`

## 目录说明

- `backend/`：后端服务（FastAPI）
- `frontend/`：前端静态页面
- `generated/docs/`：文档版本产物（需求/方案/架构/评审/集成）
- `generated/code/`：代码版本产物（代码编写阶段）

## 关键能力

1. **逐步门控执行**：每一步完成后由人决策进入下一步或要求重做。
2. **回退重跑**：进入后续步骤后，前序步骤仍可重跑并生成新版本。
3. **可编辑产出**：需求分析、方案设计、架构设计支持在线编辑并保存。
4. **历史版本管理**：方案设计、架构设计、代码编写支持历史版本查看/选定/删除。
5. **输出契约**：每一步定义输出结构；代码输出要求完整文件内容并可识别保存。
6. **版本复制策略**：版本迭代时，未修改文件从源版本目录复制到目标版本目录。
7. **代码编写输入拼接**：编写/修改代码时，自动附带上传方案与架构文档，并以 Markdown 拼接当前全部代码文件。
